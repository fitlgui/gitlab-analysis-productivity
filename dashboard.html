Bem-vindo ao Dashboard!

Para gerar as métricas de engenharia da sua equipe, você precisará de duas informações do GitLab:

  1. Token de Acesso: Vá no GitLab em Preferences > Access Tokens e crie um token marcando as opções api e read_repository.
  2. Project ID: Fica logo abaixo do nome do projeto na página inicial do seu repositório (ex: 30811897).

🔒 Privacidade: Seus dados rodam 100% no seu navegador. Nenhuma credencial é salva no servidor.
